# IELTS Reading Room

Open `index.html` in your browser, or publish this folder with GitHub Pages. The library contains 100 tests with 40 questions each.

The site uses only HTML, vanilla JavaScript, CSS and local images. All passages, questions, answer mappings and source provenance are embedded in `data.js`. Keep `assets/` because it contains the recovered diagrams.

Search by passage title, test number or question type; filter by type and sort by score or fastest completion. Submit to review answers, then use Save JSON to download your result.

The timer runs for 60 minutes, turns red in the last 10 minutes, warns at 10 and 5 minutes, and submits automatically at zero. One unfinished draft, attempt counts, best scores and completion times are saved in this browser. Reload resumes the draft and its original deadline. Start fresh or Retake clears answers and resets the timer. Progress does not sync across devices.

Select text to highlight it. Appearance supports System, Light and Dark. Highlights restore with the unfinished draft; removing or clearing a highlight updates that draft. Fresh start and Retake clear highlights. Submission clears the draft, so submitted-review highlights are not saved across reloads.

No Python, server or installation is required. Original text exports, separate JSON copies, repair records and import tools have been removed. Future test additions must update `data.js` and add an HTML entry page.
